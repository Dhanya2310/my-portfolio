# Dhanya Naik Portfolio

A React + Vite portfolio website.

## Requirements
- Install Node.js LTS (includes npm): https://nodejs.org/

## Run on Windows
1. Extract this ZIP to a folder.
2. Open that folder in VS Code.
3. Open Terminal > New Terminal.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the Local URL printed in the terminal (usually http://localhost:5173/).

## Create a production build
```bash
npm run build
npm run preview
```

Do not copy `node_modules` between different operating systems. It is intentionally excluded from this ZIP; `npm install` creates the correct dependencies for your computer.
